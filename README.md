A desktop app (macOS and Windows) that gives people who don't program an AI agent set up the way developers set up
their own: it works in their projects, browses in its own browser, runs on schedules and keeps a memory of them in
plain files.

- What it is and why: [docs/design/piko](docs/design/piko/README.md).
- How the repo is built: [ARCHITECTURE.md](ARCHITECTURE.md); setup is `zsh setup.sh`.
- The logo, the mascot Piko and the app icons: [docs/brand](docs/brand/README.md).
